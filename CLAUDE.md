# Skills a usar siempre en este proyecto

Cuando el trabajo toque estos temas, consulta el skill correspondiente antes de improvisar solo con conocimiento general:

- `react-patterns` — al escribir o revisar componentes React/Next.js (hooks, server/client boundaries, formularios, etc.).
- `database-migrations` — al generar o revisar migraciones de Drizzle, cambios de schema, rollbacks.
- `postgres-patterns` — al diseñar queries, índices, o cuando una consulta se vea lenta.
- `security-review` — al tocar autenticación, inputs de usuario, o endpoints/server actions.
- `backend-patterns` — al escribir o revisar server actions / rutas API de Next.js.
